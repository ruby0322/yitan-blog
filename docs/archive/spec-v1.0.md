# 胰探究竟 — 章醫師的胰臟日常 BLOG 設計規格

**Brand Design System v1.0**

---

## 概述

| 項目 | 說明 |
|------|------|
| **網站定位** | 暖白色醫療雜誌風（Magazine Layout），以 16:9 投影片直接作為部落格圖片 |
| **設計目標** | 兼具醫療專業、文青質感、科技感、長時間閱讀舒適 |

---

## 一、品牌核心

- **網站背景**：暖白色（`#FAF8F5`）
- **投影片**：暖白底、16:9、可直接輸出為部落格圖片
- **圖片**：保留大量留白，不加外框、不加陰影
- **風格**：Magazine / Nature / Apple Health / Nordic Medical
- **主色**：Sage Green + Blue Gray

---

## 二、品牌色票

| 元素 | 用途 | HEX |
|------|------|-----|
| 網站背景 | 暖白 | `#FAF8F5` |
| 卡片背景 | 米白 | `#F5F3EF` |
| 主標題 | 深灰 | `#2B2B2B` |
| 內文 | 中灰 | `#5C5C5C` |
| 次標 | 灰藍 | `#607D8B` |
| 重點色 | Sage Green | `#8DAA91` |
| 線條 | 淺灰 | `#D9D6D2` |
| CTA | 深綠 | `#6F8D7A` |
| Hover | 淺鼠尾草綠 | `#E6EFE8` |

---

## 三、PPT 母片規範

1. **封面**：大標＋副標＋分類＋品牌名稱
2. **內容頁**：一頁一個重點
3. **圖文比例建議**：60% 圖片 / 40% 文字
4. **結尾頁**：Take Home Message（三個重點）

---

## 四、部落格內頁版型

文章頁由上至下的區塊順序：

1. H1 標題
2. 摘要
3. Hero 圖（16:9）
4. 文章正文
5. 投影片
6. FAQ
7. CTA
8. 上一篇 / 下一篇

---

## 五、設計原則

- 大量留白
- 不使用厚重外框
- 線條式 Icon
- 圖片保持原始 16:9 比例
- 全站維持一致品牌色彩
