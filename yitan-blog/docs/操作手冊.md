# 胰探究竟 — 後台操作手冊

> 給章醫師使用的簡易指南（繁體中文）

---

## 1. 登入後台

1. 開啟瀏覽器，前往 **`https://您的網域/admin`**
2. 輸入 Email 與密碼
3. 點選「登入」

---

## 2. 後台主要功能

| 選單 | 用途 |
|------|------|
| **文章** | 撰寫、編輯、發布部落格文章 |
| **頁面** | 編輯首頁、關於頁等固定頁面 |
| **媒體庫** | 管理已上傳的圖片 |

---

## 3. 發布新文章

### 步驟

1. 左側選單點 **「文章」** → **「建立新項目」**
2. 填寫 **標題**
3. 在 **內容** 分頁撰寫文章正文
4. （選填）上傳 **封面圖**
5. 點 **「儲存草稿」** 先保存
6. 確認無誤後，點 **「發布」**

### 插入圖片

**方法一：直接在內文中插入**

1. 在編輯器中要插入的位置點一下
2. 點工具列的 **上傳 / 媒體** 按鈕
3. 選擇「上傳新圖片」或從媒體庫選取
4. 填寫圖片替代文字（alt，簡述圖片內容）

**方法二：先上傳到媒體庫**

1. 左側選 **「媒體庫」** → 上傳圖片
2. 回到文章編輯器，用媒體按鈕插入

### 插入表格

1. 在編輯器中要插入的位置點一下
2. 點工具列的 **表格** 按鈕（或輸入 `/table`）
3. 設定行數與列數
4. 點選儲存格即可輸入文字
5. 可用表格選單新增/刪除行列

> 表格功能目前為實驗性功能，若遇到異常請先以文字條列代替，並聯繫維護人員。

---

## 4. 預覽與草稿

- **草稿**：尚未公開，訪客看不到
- **預覽**：編輯時可點「預覽」查看發布前效果
- **發布**：確認後才會出現在網站 `/posts` 列表

建議流程：**撰寫 → 存草稿 → 預覽 → 發布**

---

## 5. 編輯首頁與關於頁

1. 左側選 **「頁面」**
2. 點選 **「首頁」** 或 **「關於」**
3. 修改 Hero 區塊或內容區塊
4. 儲存草稿 → 預覽 → 發布

---

## 6. 常見問題

**Q：發布後網站沒更新？**  
A：稍等 1–2 分鐘再重新整理。若仍無更新，請聯繫維護人員。

**Q：圖片裁切後前台沒變？**  
A：需重新 **發布** 使用該圖片的頁面或文章。

**Q：忘記密碼？**  
A：請聯繫網站維護人員重設，不要自行嘗試多次以免鎖定。
